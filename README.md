# 📱 Mobile Sales Data Analytics Dashboard

An end-to-end data analytics portfolio project analyzing **50,000+ rows of mobile sales data** to uncover key business trends, brand performance, and consumer purchasing behavior.

## 📊 Project Overview
This project focuses on transforming raw mobile sales data into actionable business insights. Using **Tableau**, an interactive dashboard was built to help stakeholders track sales performance dynamically across different timelines, brands, and payment methods.

---

## 🛠️ Tools & Technologies Used
* **Data Visualization & Dashboarding:** Tableau Public
* **Data Preparation / Cleaning:** Python (Pandas, NumPy) / Google Sheets / SQL
* **Version Control:** Git & GitHub

## 📈 Key Visualizations & Insights Included in the Dashboard

1. **Monthly Sales Trend (Line Chart):**
   * Tracks the sales trajectory month-over-month from late 2023 through 2025[cite: 3].
   * Highlights peak sales seasons and overall market growth.

2. **Brand Comparison Analysis (Bar Chart):**
   * Compares total revenue generated by top mobile brands (e.g., Apple, Samsung, OnePlus, Xiaomi, Vivo, etc.)[cite: 5].
   * Identifies top market performers and volume drivers.

3. **Payment Method Analysis (Bar Chart):**
   * Evaluates customer preferences across various payment gateways (UPI, Credit Card, Debit Card, EMI, Cash)[cite: 6].
   * Showcases dominant transaction modes (with UPI leading the channels)[cite: 6].
